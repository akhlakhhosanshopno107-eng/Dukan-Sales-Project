# Dukan Sales Data Analysis Project

## 📌 Project Overview
This project is an end-to-end data analysis of a real-world family clothing and tailoring business. The goal was to extract actionable insights from raw sales data to understand customer behavior, identify top-performing products, and analyze seasonal sales trends.

## 🛠️ Tools & Technologies Used
*   **Python (Pandas, Matplotlib, Seaborn):** For data cleaning, manipulation, and creating visualizations.
*   **SQL (PostgreSQL):** For database management and querying structured data.
*   **Power BI:** For building an interactive dashboard to visualize key performance indicators (KPIs).
*   **Microsoft Excel:** Used as the primary data source.

## 📊 Key Insights Extracted
*   **Top Product:** "Three-piece" is the highest revenue-generating item for the shop.
*   **Seasonal Trend:** Sales spike significantly between April and September, with the highest sales occurring in September.
*   **VIP Customers:** Identified top 5 customers based on total purchase amount to help the business focus on customer retention.
*   **Due Management:** Analyzed total outstanding dues and identified customers with pending payments.

## 📁 Repository Structure
*   `Dukan project.xlsx`: The raw dataset containing 280 rows of sales data.
*   `Final Project.ipynb`: Jupyter Notebook containing the Python code for data cleaning, EDA (Exploratory Data Analysis), and visualization.
*   `Dukan Project.pbix`: The Power BI source file for the interactive dashboard.
*   `Screenshot...png`: A preview image of the Power BI dashboard.
*   `README.md`: Project documentation.
